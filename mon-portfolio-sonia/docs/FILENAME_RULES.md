# Filename rules for submission

Rename key deliverable files so they include your first and last name (example: `Sonia_Ndione_README.md`). This helps graders identify your work.

Suggested renames:
- `README.md` → `README_Sonia_Ndione.md` (or keep `README.md` and include your name in the top)
- Diagrams: `USE_CASE_Sonia_Ndione.mmd`, `DB_SCHEMA_Sonia_Ndione.mmd`
- Exported UML/ER images: `Sonia_Ndione_UML.png`, `Sonia_Ndione_DB.png`

You can keep code files as-is, but any deliverables in `docs/` should include your name.
